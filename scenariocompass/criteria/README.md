# Evaluation criteria for the Scenario Compass

This folder contains the evaluation criteria for the Scenario Compass ensemble.
The format of the files is consistent with the specifications of the
[nomenclature-iamc](https://nomenclature-iamc.readthedocs.io) package.

See https://scenario-evaluation-criteria.iamconsortium.org/2026.08.03/ for the
rationale of the different criteria and detailed sources of the reference values.

> [!WARNING]
> The meta-indicator **"Sustainability Concern|Exceeding Prudent Limit For Geological Carbon Storage|World"**
> is currently implemented directly in the package source code and not via the yaml files
> in this directory.
